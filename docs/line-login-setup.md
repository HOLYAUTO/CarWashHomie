# LINEログイン会員化 セットアップ手順（オーナー作業）

カードコレクション機能（Phase 1b）の「LINEログインで会員化」を有効にするための、
オーナー側の設定手順です。コード側はすでに実装済みで、下記の環境変数が
セットされると自動的に機能が有効になります（未設定の間は安全に無効化され、
ゲスト収集はそのまま動きます）。

本番ドメイン: `https://carwashhomies.com`

---

## 1. LINE Developers でプロバイダーとチャネルを作成

1. https://developers.line.biz/console/ にログイン（店舗のLINEアカウントでOK）
2. **プロバイダー**がなければ新規作成（例: `Car Wash Homies`）
3. そのプロバイダーで **「LINEログイン」チャネル**を新規作成
   - チャネル名: 例「Car Wash Homies カード」
   - アプリタイプ: **ウェブアプリ**にチェック

## 2. コールバックURLを登録

チャネルの **「LINEログイン設定」** タブ → **コールバックURL** に以下を登録します
（改行で複数登録可）。

- 本番: `https://carwashhomies.com/api/line/callback`
- （動作確認でVercelプレビューを使う場合のみ）対象のプレビューURL +
  `/api/line/callback` も追加。プレビューURLはデプロイごとに変わるため、
  恒久運用では本番だけで十分です。

## 3. 公式アカウントと連携（友だち追加を促す）

同じ「LINEログイン設定」タブの **「リンクされたLINE公式アカウント」** で、
店舗の公式アカウントを選択します。
これでログイン時に「友だち追加」を促せ、告知配信の母数を増やせます。
（未連携でもログイン自体は動作します。その場合は友だち追加の促しだけ出ません）

## 4. Channel ID / Channel Secret を控える

- **チャネル基本設定** タブ → **チャネルID**
- 同タブ → **チャネルシークレット**

この2つを次のステップで Vercel に設定します。シークレットは第三者に
共有しないでください。

## 5. Vercel に環境変数を設定

Vercel の対象プロジェクト（`carwashhomie`）→ **Settings → Environment Variables**
で、以下の3つを **Production**（必要なら Preview も）に追加します。

| 変数名 | 値 |
| --- | --- |
| `LINE_LOGIN_CHANNEL_ID` | 手順4のチャネルID |
| `LINE_LOGIN_CHANNEL_SECRET` | 手順4のチャネルシークレット |
| `MEMBER_SESSION_SECRET` | ランダムな長い文字列（下記） |

`MEMBER_SESSION_SECRET` はログインCookieの署名鍵です。次のような長い
ランダム値を使ってください（ターミナルで `openssl rand -hex 32` でも生成可）。

```
（32バイトのランダム16進文字列を貼り付け）
```

> 既存の `ADMIN_SESSION_SECRET` がある場合はそれが自動フォールバックとして
> 使われますが、管理者用と会員用は分けておくのが安全なので、専用の
> `MEMBER_SESSION_SECRET` を設定することを推奨します。

## 6. 再デプロイ

環境変数を追加したら、Vercel で **Redeploy**（または次のpushで自動デプロイ）。
反映後、サイトの `/book` ページに緑の「LINEではじめる / ログイン」ボタンが
表示されれば成功です。

---

## 動作確認チェックリスト

- [ ] `/book` に「LINEではじめる / ログイン」ボタンが表示される
- [ ] ボタン → LINE認証画面に遷移し、（連携済みなら）友だち追加の案内が出る
- [ ] 認証後 `/book` に戻り「LINEでログインしました」トーストが出る
- [ ] ログイン前にゲストで集めたカードが、ログイン後も残っている（引き継ぎ）
- [ ] 別の端末／ブラウザで同じLINEでログインすると、集めたカードが同期される
- [ ] ログアウトできる

## 取得する個人情報（プライバシーポリシー 07 に記載済み）

- LINEユーザー識別子 / 表示名 / プロフィール画像URL / 公式アカウント友だち状況
- 集めたカードの取得状況（カードコード・取得日時）

## トラブル時

- ボタンが出ない → 環境変数が本番に入っているか、再デプロイ済みか確認
- ログインでエラー（`/book?login=error`）→ コールバックURLの綴りが
  `https://carwashhomies.com/api/line/callback` と完全一致しているか確認
- 友だち追加の案内が出ない → 手順3の「リンクされたLINE公式アカウント」未連携
