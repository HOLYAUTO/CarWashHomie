# ヒアリングシート（新規店舗用）

> 1店舗につき1枚コピーして埋める。右の「反映先」は、答えをどのファイルに入れるか。
> 現場（店舗）で施工の様子と写真素材を見ながら聞くのが基本。

店舗名：　　　　　　　　　　　　　記入日：　　　　　　　　記入者：

## 1. 基本情報

| 項目 | 回答 | 反映先 |
|---|---|---|
| 店名（正式表記） | | `BUSINESS.nameJa` |
| 店名（英字表記） | | `BUSINESS.nameEn` |
| キャッチコピー | | `BUSINESS.tagline` |
| ロゴ横の短い肩書き（例：コーティング専門店） | | `BRAND.mark` |
| 電話番号 | | `BUSINESS.phone` ほか |
| メールアドレス（問い合わせ受信用） | | `BUSINESS.email`・`.env` |
| Instagram / X / 公式LINE の URL | | `BUSINESS.*Url` |
| 郵便番号・住所 | | `BUSINESS` の住所欄 |
| 営業時間（開店・閉店） | | `BUSINESS.opens` / `closes` |
| 定休日 | | `BUSINESS.closedDays` |
| インボイス登録番号 | | `BUSINESS.registrationNumber` |
| 代表者名・肩書き・資格 | | `BUSINESS.operator` / `operatorTitle` |
| ドメイン（取得済み／希望） | | `SITE.url` |
